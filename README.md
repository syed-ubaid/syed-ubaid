### 📊 Featured Projects

#### [DataInsight Dashboard](https://github.com/syed-ubaid/data-insight-dashboard)
*A professional Streamlit-based data visualization platform for interactive business intelligence and automated insights.*
- **Tech**: Python, Streamlit, Pandas, Plotly
- **Key Analysis**: Dynamic filtering, real-time KPI tracking, and interactive regional distributions.

#### [SysMonitor](https://github.com/syed-ubaid/sys_monitor)
*A real-time system resource monitoring dashboard for the terminal — tracks CPU, Memory, Disk, and Network usage live.*
- **Tech**: Python, psutil, rich
- **Key Features**: Live refresh at 4 Hz, cross-platform (Windows/macOS/Linux), disk-usage breakdowns.

#### [FutureChat](https://github.com/syed-ubaid/future_chat)
*A next-generation AI chat interface built with Next.js 14 — glassmorphism UI, smooth animations, and real-time typing simulation.*
- **Tech**: Next.js 14, React 18, Tailwind CSS, TypeScript
- **Key Features**: App Router architecture, responsive design, interactive message animations.

#### [Sentiment Scope](https://github.com/syed-ubaid/sentiment_scope)
*An AI-driven sentiment analysis tool using NLP techniques to gauge public opinion from text data.*
- **Tech**: Python, FastAPI, NLTK, Docker
- **Key Analysis**: Text preprocessing, TF-IDF feature extraction, sentiment classification.

#### [DocuMind](https://github.com/syed-ubaid/docu_mind)
*A lightweight RAG (Retrieval-Augmented Generation) system for querying a personal knowledge base via CLI.*
- **Tech**: Python, Scikit-learn (TF-IDF + Cosine Similarity)
- **Key Features**: Interactive and argument-based query modes, extensible knowledge base.

#### [DevUtils](https://github.com/syed-ubaid/dev_utils)
*A collection of CLI productivity tools — project scaffolding, file organization, and directory analytics.*
- **Tech**: Python, argparse
- **Key Features**: Unified CLI interface, file organizer by extension, project template generation.

#### [Algo Daily](https://github.com/syed-ubaid/algo_daily)
*A collection of daily algorithmic challenges and solutions demonstrating problem-solving logic.*
- **Tech**: Python, Algorithms, Data Structures
- **Focus**: BFS/DFS, A\* Search, Dijkstra's, Merge Sort, Binary Search.
